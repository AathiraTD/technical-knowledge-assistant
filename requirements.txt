# Five dependencies. Each one is argued for in DECISIONS.md; nothing here is habitual.
# Pinned from the build environment: Python 3.13 on Windows ARM64, 15 September 2026.

# Crawling, and the Ollama HTTP API. No Ollama client library: it would wrap two endpoints.
httpx==0.28.1

# HTML parsing. Chosen over trafilatura because the pipeline needs the DOM anyway —
# documents are classified by link text (never by filename), and the product, colour and
# merchant name lists are harvested before boilerplate stripping removes them.
beautifulsoup4==4.15.0
lxml==6.1.3

# PDF text extraction. The only extractor that returned a clean text layer in the
# decision-0 probe; a plain HTTP fetch cannot read these files at all.
pymupdf==1.28.2

# The chunk store: cosine similarity over one array. No vector database at this scale.
numpy==2.5.3

# No Streamlit. It pulls pyarrow, which publishes no Windows ARM64 wheel and falls back to
# a source build requiring MSVC build tools. That is a clean-clone failure on any ARM64
# machine, including an assessor's, so the web UI is served from the standard library
# instead — see DECISIONS.md entry 15.
